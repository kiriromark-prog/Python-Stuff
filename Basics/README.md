# Python Basics & Fundamental Exercises

A collection of foundational Python scripts and mini-projects demonstrating core programming concepts, data structures, control flow, and basic interactive logic.

---

## Directory Overview

This directory contains standalone scripts designed to practice key Python fundamentals:

* **Games & Logic:**
  * `Num Guesser.py` – Interactive number guessing game utilizing user input and conditional logic.
  * `Rock Paper Scissors.py` – Classic decision-making game using Python's `random` module.
  * `pokemon.py` – Practice with classes, object-oriented programming (OOP), or data lookup patterns.
* **Data Structures & Collections:**
  * `Car library.py` & `Cars library 2.py` – Exercises focusing on dictionaries, lists, and data manipulation.
  * `Music_library.py` – Structured data collection and retrieval using nested dictionaries or lists.
* **Core Concepts:**
  * `T2T.py` – Text processing or basic algorithm implementation.

---

## Core Concepts Covered

This module serves as a reference for:
* **Control Flow:** `if / elif / else` statements, `while` loops, and `for` loops.
* **Data Structures:** Dictionaries, lists, strings, and tuple handling.
* **Functions & Modules:** Code modularization and importing built-in modules like `random` or `sys`.
* **Object-Oriented Programming (OOP):** Basic class definition and instantiation.
